# Portfolio Full-Stack Application

This repository contains both parts of the application:

- `Portfolio/` - React and Vite frontend
- `server/` - Node.js and Express MVC backend

See [Portfolio/README.md](Portfolio/README.md) for setup instructions, API documentation, and curl checks.

## Run

Backend, from `server/`:

```bash
npm install
npm start
```

Frontend, from `Portfolio/`:

```bash
npm install
npm run dev
```
